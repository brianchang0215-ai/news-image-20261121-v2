# Sum up 21 November 2026 world news in one image

A Python program that draws one image summing up the world news of
Saturday 21 November 2026. It uses only the Python standard library,
needs no network and no font files, and writes the same PNG bytes
on every run.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is `out/entry.png`, at most 1024 by 1024 pixels and
under 1 MiB.
